# Flappy Bird

A simple Flappy Bird clone built with Python and Pygame.

## How to Play

- Press **SPACE** to start the game.
- Press **SPACE** to make the bird flap/jump.
- Avoid hitting the pipes, the ground, or the ceiling.
- Every pipe you pass adds 1 to your score.
- When you crash, press **SPACE** to restart.

## Setup

Requires Python 3 and [Pygame](https://www.pygame.org/).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pygame
```

## Run the Game

```bash
python main.py
```

(or `.venv/bin/python main.py` if your virtual environment isn't activated)
